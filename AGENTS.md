# Agent onboarding

Before starting project work, help the teammate prepare their own checkout. Read `TEAMWORK.md` for the shared workflow and the event deadline.

1. Check the current directory, Git branch, working-tree status, and `origin` remote. Preserve existing changes and do not reset, overwrite, or switch branches over uncommitted work.
2. Check that GitHub CLI authentication and access to `bratadeepsarkar123/crustdata-hackathon-2026` work for the teammate's own GitHub account. If authentication or access is missing, explain the necessary sign-in or invitation step; do not switch another person's active account globally.
3. Check the effective Git author name and email. If missing or incorrect, configure the right identity for this repository only, using the teammate's confirmed name and email or GitHub no-reply address. Do not change global Git configuration.
4. Check Git, Node.js, and npm availability and report missing tools. If PowerShell blocks `npm.ps1`, try the Windows `npm.cmd` command without changing the execution policy. The application stack is not yet decided; do not scaffold an application or install project dependencies until the team chooses a direction.
5. Help the teammate find the GitHub issue for their task and coordinate branch and file ownership. Before editing, agree on the task and avoid concurrent changes to shared files. Report blockers and checks in the issue or handoff.
6. Event API and model credentials are not assumed to be available. If issued, check only whether they are configured and what access is needed; never print, commit, paste into chat or share a key. There is no repository-level `.gitignore` yet, so check ignore rules before creating local secret files.

The ContextCon event page says application coding begins at 11:00 PM on November 5, 2026. Follow any newer instructions from the organizers. Do not start application implementation before the allowed time or before the user has chosen what to build.
